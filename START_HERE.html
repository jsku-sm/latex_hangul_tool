WINDOWS + MAC · OFFLINE TOOL

LaTeX를 한글 수식으로.

학습지의 분수, 근호, 행렬을 편집 가능한 한글 수식으로 바꾸세요. Python 실행 도구와 운영체제별 시작 파일이 들어 있습니다.

먼저 확인

공통으로 사용할 수 있는 방법

도구에 LaTeX를 붙여넣고 HWPX 저장을 누르세요. 생성 문서를 한글에서 열면 수식 개체가 들어 있습니다. 수식을 복사해서 원래 문서에 붙여넣고, 두 번 눌러 수정할 수 있습니다.

sample_equations.hwpx를 먼저 열어 예제 수식이 보이는지 확인하세요.

검증 범위: 변환·문서 구조 자동 테스트 13개 통과. 실제 Windows/Mac 한글에서의 표시와 자동 입력은 미검증 상태입니다. 맥 자동 입력은 실험 기능으로 제공됩니다.
WINDOWS

윈도우에서 시작하기

  1. Python 3.10 이상과 편집 가능한 한글을 준비합니다.
  2. ZIP을 모두 압축 해제합니다.
  3. setup_windows.cmd를 한 번 실행합니다. 최초 설치에는 인터넷이 필요합니다.
  4. run_windows.cmd를 실행합니다.

한글에 바로 입력

LaTeX 복사 → 한글 본문에서 위치 클릭 → Ctrl + Alt + M.

도구가 실행 중이어야 합니다. 일반 Ctrl+V는 바꾸지 않습니다. 자동화 연결이 안 되면 HWPX 저장을 사용하세요.

MAC

맥북에서 시작하기

  1. python.org의 Python 3.10 이상과 편집 가능한 한글을 준비합니다.
  2. ZIP을 모두 압축 해제합니다.
  3. run_mac.command를 실행합니다.
  4. 수식을 넣고 HWPX 저장을 누릅니다.

자동 입력 · 실험 기능

한글에 자동 입력을 누르고 5초 안에 한글 본문을 클릭하세요. 도구가 수식 편집기를 열고 입력합니다.

손쉬운 사용/자동화 권한이 필요합니다. 한글 버전에 따라 동작하지 않을 수 있습니다. 수식 한 개만 지원하며 크기는 한글 기본값을 따릅니다.

맥 단축키 추가하기

install_mac_shortcuts.command를 실행한 뒤 시스템 설정 → 키보드 → 키보드 단축키 → 서비스에서 다음 키를 지정하세요.

서비스하는 일권장 단축키
LaTeX_Hangul_Insert클립보드의 수식을 현재 한글에 자동 입력 · 실험 기능⌃⌥⌘M
LaTeX_Hangul_HWPX클립보드의 수식을 HWPX로 만들어 열기⌃⌥⌘H

두 번째 서비스 결과는 Documents/LaTeX-Hangul 폴더에 저장됩니다. 폴더를 옮겼다면 설치 파일을 다시 실행하세요. 서비스는 ~/Library/Services의 해당 .workflow 폴더를 삭제하면 제거됩니다.

수식 입력 예시

수식 한 개

x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}

문장 + 여러 수식

다음 식을 정리하시오: $\frac{x+1}{2}$
행렬 $A=\begin{pmatrix}1&2\\3&4\end{pmatrix}$를 살펴보자.

두 번째 방식은 문장 + 여러 수식 모드를 선택하세요. 문서의 일반 글과 수식 순서를 유지하며 HWPX에 넣습니다. Markdown 표·이미지·제목 스타일은 변환하지 않습니다.

지원 범위와 오류 안내

분수, 근호, 첨자, 극한, 적분, 시그마, 삼각함수, 로그, 대표 그리스 문자, 집합, 부등호, 조합, 벡터 및 matrix·pmatrix·bmatrix·vmatrix·cases를 지원합니다.

사용자 정의 명령, LaTeX 전체 문서, TikZ, align·array 및 일부 특수 명령은 지원하지 않습니다. 오류가 나면 명령을 확인하거나 수식을 나누어 주세요.

  • 한 수식은 10,000자까지, 작업 하나는 수식 200개까지 지원합니다.
  • 수식 크기는 HWPX와 Windows 자동 입력에서 8~32pt로 지정합니다.
  • Mac 자동 입력 실패 시 열려 있는 수식 창을 취소하고 HWPX 저장을 사용하세요.
  • HWPX 수식 크기는 추정값이며 한글 버전·글꼴에 따라 간격이 달라질 수 있습니다.

.command 파일이 실행되지 않을 때

터미널에서 압축 해제한 폴더로 이동하고 다음을 실행하세요.

chmod +x run_mac.command install_mac_shortcuts.command
python3 app.py

자세한 내용은 README.txt를 참고하세요. 이 패키지는 Python 소스와 실행 스크립트이며 EXE/DMG 설치 파일은 아닙니다.

입력 내용을 외부 서버로 전송하지 않습니다. 한글 문서를 자동 저장하거나 닫지 않습니다.
